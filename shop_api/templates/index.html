Shop Orders API

A REST API for a local restaurant or shop, built with Python and Flask. Customers browse the menu and place orders, and every order comes back with a WhatsApp link that sends it straight to the shop owner's phone.

Try it

The response will show here.

Endpoints

MethodPathWhat it does
GET/api/productsList products. Filter with ?category=mains
GET/api/products/<id>One product
POST/api/ordersPlace an order. Validates input, totals the bill, returns a WhatsApp link
GET/api/orders/<id>Track an order
GET/api/ordersShop owner: all orders (needs X-API-Key)
PATCH/api/orders/<id>Shop owner: move an order to preparing, ready, delivered or cancelled

Example

curl -X POST {{ request.host_url }}api/orders \
  -H "Content-Type: application/json" \
  -d '{"customer_name":"Ravi","phone":"9876543210","items":[{"product_id":1,"qty":2}]}'

This demo keeps orders in memory, so they reset when the server restarts. Source and tests: github.com/Bpavan2525/restapi_flask
